# CMEC E-Borrow — เวอร์ชัน Google Sheets + Apps Script

ระบบเดียวกับเวอร์ชัน Node.js แต่ข้อมูลอยู่ใน Google Sheet และรันบน Google ฟรี ไม่ต้องเปิดเครื่องเซิร์ฟเวอร์ทิ้งไว้

**ต่างจากเวอร์ชันเดิม**
- ผู้ยืมไม่ต้อง login: กรอกชื่อ หน่วยงาน เบอร์โทรตอนจอง ดูและยกเลิกการจองของตัวเองด้วยเบอร์โทร
- มีแค่บัญชี Admin (ปุ่ม "เข้าสู่ระบบ Admin" อยู่ในเมนูมุมขวาบน)
- รูปหุ่นเก็บใน Google Drive
- แต่ละคำสั่งช้ากว่าเดิมเล็กน้อย (ราว 1–3 วินาที)

## ไฟล์ในโฟลเดอร์นี้
| ไฟล์ | คืออะไร |
| --- | --- |
| `src/Code.gs` | ส่วนเซิร์ฟเวอร์ (API ทั้งหมด + ฟังก์ชันตั้งค่า) |
| `src/Index.html`, `src/app.js` | หน้าเว็บ (ใช้ CSS จาก `public/css/style.css`) |
| `build.js` | รวมไฟล์เป็นชุดที่พร้อมวางใน Apps Script ไว้ที่ `dist/` |
| `test/backend.test.js` | ทดสอบส่วนเซิร์ฟเวอร์กับ Google จำลอง |
| `test/dev-server.js` | เปิดดูหน้าเว็บในเครื่องที่ http://localhost:3100 (ข้อมูลจำลอง) |

## สร้างไฟล์ที่จะนำไปวาง
```powershell
node apps-script/build.js
```
ได้ไฟล์ใน `apps-script/dist/`: `Code.gs`, `Index.html`, `Style.html`, `App.html`, `appsscript.json` และ `SeedData.gs` (ข้อมูลเดิมจาก `data/eborrow.db` — **มีชื่อและเบอร์โทรของผู้ใช้ ห้ามแชร์**; โฟลเดอร์ `dist/` ไม่ถูกส่งขึ้น GitHub)

## ติดตั้งครั้งแรก (ประมาณ 30 นาที)
ใช้บัญชี Google กลางของศูนย์ ไม่ใช่ Gmail ส่วนตัว ระบบและข้อมูลจะผูกกับบัญชีนี้

1. **สร้าง Google Sheet ใหม่** ตั้งชื่อเช่น `CMEC E-Borrow` แล้วเมนู **ส่วนขยาย → Apps Script**
2. **ตั้งค่าโปรเจกต์:** ไอคอนรูปเฟือง (การตั้งค่าโปรเจกต์) → ติ๊ก **แสดงไฟล์ Manifest "appsscript.json" ในเครื่องมือแก้ไข** → กลับไปหน้าแก้ไข เปิด `appsscript.json` แล้ววางเนื้อหาจาก `dist/appsscript.json` ทับ
3. **วางโค้ด:** เปิด `Code.gs` ลบของเดิม แล้ววางเนื้อหา `dist/Code.gs`
4. **เพิ่มไฟล์ HTML 3 ไฟล์:** กด **+ → HTML** ตั้งชื่อ `Index`, `Style`, `App` (ตรงตามนี้ ไม่ต้องใส่ .html) แล้ววางเนื้อหาจากไฟล์ชื่อเดียวกันใน `dist/`
5. **(ถ้าจะย้ายข้อมูลเดิม)** กด **+ → สคริปต์** ตั้งชื่อ `SeedData` แล้ววาง `dist/SeedData.gs`
6. กด **บันทึก** แล้วเลือกฟังก์ชัน **`setup`** ในแถบด้านบน → **เรียกใช้**
   - ครั้งแรก Google จะขอสิทธิ์ → เลือกบัญชี → ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง → ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต** (เป็นสคริปต์ของเราเอง)
   - ดู **บันทึกการดำเนินการ** ด้านล่าง: จะมี **รหัสผ่าน Admin** และ **ลิงก์โฟลเดอร์รูปหุ่น** — จดไว้
7. **(ถ้าย้ายข้อมูลเดิม)** เลือกฟังก์ชัน **`importSeedData`** → เรียกใช้ แล้ว **ลบไฟล์ `SeedData`** ออกจากโปรเจกต์
8. **อัปโหลดรูป:** เปิดลิงก์โฟลเดอร์รูปจากขั้นที่ 6 ลากไฟล์ทั้งหมดในโฟลเดอร์ `pic/` และ `logo/Logo.jpg` ใส่ แล้วกลับมาเรียกใช้ฟังก์ชัน **`syncImagesFromFolder`**
   - ผูกรูปกับหุ่นตามรหัสในชื่อไฟล์ (`A001-ชื่อ.jpg`) ถ้าไม่ได้ย้ายข้อมูลเดิม ระบบจะสร้างรายการหุ่นจากชื่อไฟล์ให้
   - ไฟล์ชื่อ `Logo.jpg` จะกลายเป็นโลโก้ของแอป
9. **เปิดใช้งานเป็นเว็บ:** ปุ่ม **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** → ประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (ถ้าใช้ Google Workspace ของโรงพยาบาล เลือก "ทุกคนใน…" เพื่อจำกัดเฉพาะบุคลากร)
   - กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** — นี่คือลิงก์ถาวรที่แจกให้ผู้ใช้
10. เปิดลิงก์ → เมนูมุมขวาบน → **เข้าสู่ระบบ Admin** ด้วย `admin` + รหัสจากขั้นที่ 6 → **เปลี่ยนรหัสผ่านทันที**

## อัปเดตโค้ดภายหลัง
1. แก้โค้ดใน `src/` แล้วรัน `node apps-script/build.js --no-data`
2. วางไฟล์ที่เปลี่ยนทับใน Apps Script แล้วบันทึก
3. **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้** → ไอคอนดินสอ → เวอร์ชัน: **เวอร์ชันใหม่** → ทำให้ใช้งานได้ (ลิงก์เดิมยังใช้ได้)

## ทดสอบในเครื่องก่อนนำขึ้น
```powershell
node apps-script/test/backend.test.js
```
```powershell
node apps-script/build.js; node apps-script/test/dev-server.js
```
แล้วเปิด http://localhost:3100 — ข้อมูลอยู่ในหน่วยความจำ ปิดแล้วหาย รหัส Admin ชั่วคราวแสดงในหน้าต่างที่รัน

## ข้อควรรู้
- **ข้อมูลอยู่ในแท็บของ Google Sheet:** `Items`, `Bookings`, `Reports`, `Usage`, `Admins` — admin แก้ใน Sheet ได้โดยตรง แต่อย่าเปลี่ยนชื่อแท็บหรือหัวคอลัมน์ และอย่าแก้คอลัมน์ `password_hash`/`salt`
- **สำรองข้อมูล:** Google Sheet เก็บประวัติการแก้ไขให้ (ไฟล์ → ประวัติเวอร์ชัน) หรือ ไฟล์ → ดาวน์โหลด → Excel
- **รูปไม่ขึ้นสำหรับคนอื่น:** ระบบตั้งรูปเป็น "ทุกคนที่มีลิงก์ดูได้" ถ้าองค์กรปิดสิทธิ์นี้ไว้ รูปจะเห็นเฉพาะคนในองค์กร
- **ลืมรหัส Admin ทุกบัญชี:** ลบแถวในแท็บ `Admins` ให้เหลือแค่หัวตาราง แล้วเรียกใช้ `setup` ใหม่ จะได้บัญชี `admin` รหัสใหม่
- **ความเสี่ยงของการไม่ต้อง login:** คนที่รู้เบอร์โทรของคนอื่นจะเห็นและยกเลิกการจองของคนนั้นได้
